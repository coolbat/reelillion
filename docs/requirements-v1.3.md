## 目标

用一座原创像素电影院承载可直接开始的每日电影游戏；用片尾字幕推进表现累计稀有度成绩。玩家应立即理解：**答案越冷门，字幕滚得越远；高分能抵达片尾彩蛋。**

英文主线：**How far into the credits can you go?**。主操作：**Play today’s reel**（明确表示开始答题；Roll the credits 保留为主题表达）。

## 必须保持的规则与兼容性

- 每局七题，满分 700；单题五档 10/30/60/85/100，错误、跳过、超时或放弃为 0，无速度加分。
- 每题 20 秒或开局前选择 Extra time 40 秒；服务端截止时间权威，客户端按 `serverNow` 校时。
- 现有判定、三字符自动补全、未知片名可重试、已知不符锁定、同名/翻拍处理和锁分不变。
- Daily 唯一、纽约午夜重置、Daily/Practice/Archive 统计边界与本地 streak 不变。
- API、D1 schema、设备标识和旧记录不迁移；字幕等级由已有答案累计分数推导，不重新评分。
- 已有低样本说明、真实百分位门槛、榜单/发现区和数据来源边界保留；不得生成虚假玩家数据。

## 字幕进度合同

**一个成绩轴：本局累计分数。** 十个部门是游戏路标，不是十道题、额外货币、职业价值排名或统一电影署名顺序。文案使用“看到/抵达哪段字幕”。

| 路标 ID | 最低累计分 | 文字 |
| --- | --- | --- |
| opening | 0 | Opening frame（起点，不授予等级） |
| lead-actor | 1 | Lead Actor |
| supporting-actor | 70 | Supporting Actor |
| director | 140 | Director |
| screenwriter | 210 | Screenwriter |
| cinematographer | 280 | Cinematographer |
| gaffer | 350 | Gaffer |
| key-grip | 420 | Key Grip |
| best-boy | 490 | Best Boy |
| catering | 560 | Catering |
| post-credits | 600 | Post-Credits Scene |

- 最高匹配下限决定当前路标；0 分不得误报为 Lead Actor。
- UI 显示当前分数、部门与下一路标；超出最后路标后继续保留总分到 700。
- 相同已锁定总分必须得到相同路标；重复渲染和旧局读取不改变分数。
- 阈值是本版固定的初始设计，没有真实分布校准证明。后续调参应另行记录版本，不回写历史分数。

## 结算推进与可访问性

| 编号 | 必须行为 | 验收 |
| --- | --- | --- |
| V13-06 | 字幕在独立舞台滚动，题目、输入框、提交/继续固定 | 正确/错误结算时观察无网页强制滚动或控件位移 |
| V13-07 | 新增分数越多，推进距离越大；零分不前进、不倒退 | 比较 10 与 100 分；0 分保持相同累计位置 |
| V13-08 | 答案锁定后播放短推进；Next 主动开启下题 | 动画时不启动下一题计时，连续点击不重复提交 |
| V13-09 | 动画可跳过；减少动态模式立即定位或静态呈现 | `prefers-reduced-motion` 实测，分数和时间一致 |
| V13-10 | 必要信息用文字传达，键盘可操作，状态清楚 | 自动补全上下/Enter、焦点、错误重试、超时、加载与分享回退 |

字幕可以自动滚动，但滚动的是游戏独立场景，不是文档页面。动画被禁用时，最终路标和已解锁奖励仍须清楚。声音本版不提供。

## 落幕与彩蛋

| 完局总分 | 行为 |
| --- | --- |
| 0–599 | 简短落幕，完整成绩、每题答案发现与分享都可用 |
| 600–699 | 解锁主片尾彩蛋；可跳过，可在结果中识别/重看 |
| 700 | 独特的满分特别版本，仍保留普通结果操作 |

- 只在**七题完成**后播放彩蛋；第六题已到 600 不得提前完局。
- 暗场短暂且有明确过渡，不能表现为网络错误或长时间无响应。
- 全部结果应直接可读，不能强制等待彩蛋才能分享。
- 刷新/旧记录/Archive 读取不应重复触发不可跳过的长动画。
- 600 是本版初始门槛，是否适合普通高分用户需要真实分布验证；不能用测试 fixture 证明真实玩家到达率。

## 分享合同

```text
🎬 Reelillion #12
I made it to Key Grip.
435 / 700 · Daily · 20s
🎞️🎟️📼🎞️🏆🍿📼
reelillion.com
```

- 最终路标 + 0–700 总分 + 七个答案 emoji + 模式与时长 + 链接。
- 0 分使用 Opening frame；600+ 使用 Post-Credits Scene；满分可增加特别标记。
- 不包含答案、未完成题目的假成绩或十题式进度条。
- 保留真实可用的百分位/streak、Challenge a friend、原生分享、复制与手动复制回退。实际向他人发送需另有明确授权。
- Practice/Archive 分享明确模式，不暗示是当日唯一 Daily；40 秒必须标注。

## 本轮边界

本次包含：首页像素影院、游戏全过程、字幕路标/动画、落幕/彩蛋、结算分享和相关玩法说明。已有 API 与 D1、数据目录、付费边界保持兼容。

## 浏览器复查与发布验收

1. 先完成初稿，再在真实浏览器按 390/768/1440px 检查；检查中间宽度无意外溢出、遮挡或层叠问题。
2. 实际操作开局、20/40 秒、菜单、自动补全、未知答案重试、锁定反馈、Next、跳过/超时、结算、分享与减少动态。
3. 最多三轮；每轮对最影响体验的问题记录位置、现象、修改理由、修复和复查结果。重要问题全部复查通过可提前结束。
4. 为 0/各路标边界/600/700、动画不改时间或分数、旧记录派生提供有意义的测试；不把开发者设分当真实玩家结果。
5. 交付实际截图/预览与未验证项；真机、辅助阅读器或原生分享投递如未实测必须明确说明。
6. 发布按 GitHub commit → 同 SHA 必需 CI → Cloudflare Git 自动部署 → 线上验证；本地只允许构建/预览/dry-run。

交付证据放入对应的浏览器复查和发布记录；此需求文件本身不把“已写要求”标记为“已完成实现”。


首轮可读性复查修订：开局按钮使用 Play today’s reel，避免误以为只是播放一段字幕；提供游戏内 Reduce motion 和 Copy result，作为系统减少动态与原生分享之外的直接控制，不改变计分。
